# ИИС «Недроресурс»

Интеллектуальная информационная система управления предприятием ООО «Недроресурс»: добыча песка на четырёх карьерах, остатки на площадках, заказы и клиенты, рейсы самосвалов, документы, прогноз спроса и планирование рейсов.

Выпускная квалификационная работа, Московский политехнический университет, направление 09.03.02. Тема: «Разработка интеллектуальной информационной системы управления предприятием».

## Что уже работает

- вход по логину и паролю, 7 ролей, меню и права по роли;
- клиенты и адреса доставки с расстоянием от карьеров;
- заказы: расчёт цены с доставкой по тарифу (300 ₽/м³ + 200 ₽ за каждые 20 км пробега туда и обратно, НДС 22 %), проверка остатка на площадке, число рейсов, статусы заказа по диаграмме состояний;
- добыча за смену и остатки на площадках с контролем вместимости (30 000 м³);
- тарифы в настройках (меняет администратор);
- **рейсы** (этап 2): план на дату — заказы делятся на рейсы по 30 м³ и распределяются между самосвалами на линии с учётом 12-часовой смены, ручной перенос рейса, утверждение плана;
- **интерфейс водителя** для смартфона (http://localhost:8080 → вход под `driver1`): отметки «погружен» и «доставлено» с фактическим объёмом, работа без связи; при доставке списывается песок с площадки, создаются ТН и УПД, заказ переходит в «Отгружен»;
- документация API: http://localhost:8000/api/docs

- **техника** (этап 3): карточки 12 машин, ремонт и ТО с историей, интервал ТО по пробегу или моточасам и подсветка «скоро ТО», пробег самосвала растёт автоматически после каждой доставки, закрепление водителей; самосвал в ремонте не попадает в план, а его рейсы в утверждённом плане можно перенести на другую машину;

Дальше: договоры и документы → прогноз спроса и план добычи → оптимизация рейсов.

## Запуск на компьютере (Mac, Windows, Linux)

Нужен установленный и запущенный **Docker Desktop**.

1. Скачайте проект:
   ```bash
   git clone https://github.com/arinak32/nedroresurs-iis.git
   cd nedroresurs-iis
   ```
2. Создайте файл настроек из примера и впишите свои значения (пароль базы, секрет, пароль для входа):
   ```bash
   cp .env.example .env
   open -e .env        # на Mac откроется в TextEdit
   ```
3. Запустите:
   ```bash
   docker compose up --build
   ```
   Первый запуск занимает несколько минут.
4. Откройте http://localhost:8080 и войдите. Логины тестовых пользователей:
   `director`, `manager`, `buh`, `lawyer`, `mechanic`, `admin`, `driver1` … `driver10`.
   Пароль у всех — тот, что вы указали в `SEED_PASSWORD`.

Остановить: `Ctrl+C`, затем `docker compose down`. Данные базы сохраняются между запусками.
Удалить базу и начать заново: `docker compose down -v`.

## Структура

```
backend/            серверная часть (Python, FastAPI, SQLAlchemy, PostgreSQL)
  app/models.py     модель данных (19 таблиц)
  app/services/     бизнес-логика: цены, остатки, заказы
  app/api/          ресурсы REST
  alembic/          миграции базы данных
  tests/            автоматические тесты (pytest)
frontend/           клиентская часть (React, TypeScript, Vite)
docker-compose.yml  запуск всей системы
```

## Для разработки без Docker

```bash
# сервер
cd backend && python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
alembic upgrade head && python -m app.seed
uvicorn app.main:app --reload
pytest                     # тесты (нужна база nedro_test)

# интерфейс
cd frontend && npm install && npm run dev   # http://localhost:5173
```
